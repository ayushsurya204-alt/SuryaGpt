# ⚡ QuickGPT – AI Chatbot (MERN Stack)

**QuickGPT** is a full-stack **AI Chatbot application** built using the **MERN Stack (MongoDB, Express.js, React.js, and Node.js)**.
It allows users to interact with an AI assistant in real time, manage chat history, and experience a fast and responsive conversational interface.

This project demonstrates how to **build, integrate AI APIs, and deploy a production-ready chatbot application** using modern web technologies.

---

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/quickgpt.git
cd quickgpt
```

---

## 2️⃣ Install Dependencies

### Frontend

```bash
cd client
npm install
```

### Backend

```bash
cd server
npm install
```

---

## 3️⃣ Setup Environment Variables

Create a `.env` file inside the **server folder**.

```
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
AI_API_KEY=your_ai_api_key
```

---

## 4️⃣ Run the Application

### Start Backend

```
cd server
npm run dev
```

### Start Frontend

```
cd client
npm run dev
```
